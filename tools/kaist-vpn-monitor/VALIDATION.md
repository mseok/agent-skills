## 확인하지 않은 사항

- 다른 Mac·계정에서의 최초 OTP 로그인과 Gmail app-server 도구 제공 여부.
- 공유판의 실제 손쉬운 사용·전체 디스크 접근 권한 승인과 무인 재연결.
- 공유판 LaunchAgent 활성화, 사용자 로그인 후 실행, 장시간 세션 만료 후 복구.
- Intel Mac 및 다른 언어의 Ivanti 메뉴, 다른 Mail 저장 형식.

기존 개인용 자동화의 실행 상태·키체인·예약 작업·VPN 연결은 변경하지 않았습니다. 실행 중인 VPN을 끊어서 테스트하지 않았습니다. 개인용의 과거 실사용 결과를 이 공유판의 종단 간 성공으로 간주하지 않습니다.

## 공유판에서 달라진 부분

- SSH 확인 대상과 Codex 실행 경로를 각 사용자의 로컬 설정으로 분리.
- 개인용과 다른 앱 식별자, 키체인 항목, 캐시·상태 디렉터리 사용.
- 앱에 스크립트·의존성·컴파일된 보조 프로그램을 포함. 사용자 홈의 Codex skill 경로에 의존하지 않음.
- 앱 설치와 자동 실행 활성화를 분리. 오류 설명을 위한 모델 호출 제거.
- 시스템 VPN 서비스를 재시작하거나 프로필을 수정하는 관리자 권한 스크립트, 과거 SMS/전면 브라우저 보조 코드, 개인 실행 기록은 배포에서 제외.

# 공유판 검증 기록

검증일: 2026-10-13 (KST). 버전: 공유판 0.2.3, 실험적 릴리스.

## 검증 범위

- `node --test scripts/background-login/*.test.cjs`: **35개 통과, 0개 실패**. 설정·권한 모드, 재시도 경계, 잘못된 메일 후보 건너뛰기, DKIM 서명·본문·발신자·최신성·중복 헤더 검증, 브라우저 origin 정책, 실제 루프백 프록시의 외부 주소 차단, 만료·다른 요청의 OTP 제출 거부를 다룹니다. 서명 테스트는 실행 중 생성한 임시 키와 가상 DNS를 사용하며 실제 계정·메일에 접근하지 않습니다.
- 설치 스킬은 내장 `quick_validate.py`로 구조를 확인합니다. 검증기의 PyYAML은 기존 범용 pre-commit 도구 환경을 사용하며, 프로젝트에 Python 의존성을 추가하지 않습니다.
- 모든 CommonJS 파일의 `node --check`, 키체인 스크립트의 `zsh -n`, `git diff --check`를 확인합니다.
- `install.cjs --build`로 런처와 Swift 보조 실행 파일 7개를 임시 앱에 빌드합니다. 빌드 성공을 확인했습니다. 공유 기본 식별자의 설치는 이전 빌드 검증 범위입니다. 아래 개인용 적용에서 실제 설치와 예약 실행 및 새 로그인까지 추가 확인했습니다.
- 앱의 `codesign --verify --deep --strict`, Info.plist의 `plutil -lint`, 읽기 전용 `--status`를 확인했습니다. 서명 검증 종료 코드 0, plist OK, 초기 상태 `{}`를 확인했습니다.
- 고정된 의존성에 대한 `npm audit --omit=dev`: 2026-10-13 검사에서 알려진 취약점 **0건**. 알려지지 않은 문제나 외부 Chrome·Codex·Ivanti 바이너리의 안전성을 보장하지 않습니다.
- 공개 대상은 소스·설치 스킬·안내·의존성 잠금 파일·합성 테스트입니다. 개인 홈 경로·서버 별칭·개인 앱 식별자·일반적인 토큰/개인키 패턴을 점검합니다. 실제 메일·키체인·상태·브라우저 캐시는 복사하지 않습니다.

테스트 환경: Apple Silicon, macOS 26.5.1, Node 26.8.1, Codex CLI 0.153.4.
외부 Ivanti 설치 버전은 22.8.6이나 이번 검증에서는 인증·재연결을 실행하지 않았습니다.
임시 빌드에서는 도구 샌드박스의 쓰기 제한에 맞춰 `CLANG_MODULE_CACHE_PATH`를 임시 폴더로 지정합니다.

## 독립 검토

사용자의 요청에 따라 별도 **GPT-6 Astra / High** 에이전트가 소스와 합성 테스트를 검토했습니다.
v0.1.0의 메일 기반 복구 방해 및 위조 발신자 수용 문제를 확인했고, 결과를 반영해
명시적 발신자 등록·DKIM 검증·MIME 파싱·잘못된 후보 건너뛰기와 origin 제한을 추가했습니다.
독립 재검토에서 검토 범위 내의 남은 배포 차단 결함은 찾지 못했습니다. 별도 headless Chrome의 합성 307·308 POST 리디렉션이 외부 테스트 주소에서 `ERR_TUNNEL_CONNECTION_FAILED`로 차단되는 것도 확인했습니다. 사전 연결은 비활성 테스트 소켓이 받아 실제 포털 응답을 사용하지 않았습니다. 이 결과를 실제 로그인 성공으로 확대하지 않습니다.
상세 범위와 남은 위험은 [SECURITY-REVIEW.md](SECURITY-REVIEW.md)에 기록합니다.

## 확인하지 않은 사항

- 다른 계정의 최초 OTP 로그인. 실제 메일의 서명·수신 메타데이터·고정 본문 해석은 개인정보를 출력하지 않는 검사로 확인했습니다.
- 실제 macOS 손쉬운 사용 권한 승인, 공유판 LaunchAgent 활성화·로그인 후 실행·장시간 복구.
- Intel Mac, 다른 언어의 Ivanti 메뉴, 포털의 외부 CDN·팝업 요구 여부.
- 공급업체 Pulse URI 내부 의미, VPN 서버의 OTP 챌린지 연결 방식, 동일 사용자 악성 코드 방어.

기존 개인용 자동화·키체인·예약 작업·VPN 연결은 변경하지 않았습니다.
개인용의 과거 실사용 결과를 공유판 0.2.1의 종단 간 성공으로 간주하지 않습니다.
실제 복구 성공을 먼저 확인한 환경에서만 자동 실행을 켜세요.

루프백 소켓 테스트는 샌드박스에서 `listen EPERM`으로 차단돼, 승인된 격리 테스트 실행에서 완료했습니다. 실제 VPN·계정에는 접속하지 않았습니다.

## 개인용 설치 확인 중 발견한 사항

v0.2.0은 실제 KVPN 메일과 호환되지 않았습니다. v0.2.1은 서명된 Subject와
ASCII 본문, 동일 Gmail 메시지 ID의 metadata internal_date를 검증합니다.
새 개인용 앱을 깨끗한 의존성에서 빌드하고 서명 검증 및 읽기 전용 연결
검사를 통과했습니다. LaunchAgent 실행에서는 새 빌드의 손쉬운 사용 권한
재승인이 필요했습니다. 사용자가 재승인한 뒤 실제 LaunchAgent 점검이 성공했습니다. 이어서 명시적
재로그인 요청에 따라 SA를 한 번 해제하고, 기존 쿠키가 없는 새 브라우저
프로필에서 로그인 1회로 OTP와 네이티브 SA 연결 및 SSH 검증에 성공했습니다
(`attempts: 1`, `reusedConnection: false`). 5분 예약 점검을 복원했습니다.

개인용 앱은 기존 번들 식별자·Keychain 항목·SSH 설정을 유지했고, 소스와
의존성은 새로 설치했습니다. 새 Mac에서 Ivanti·Chrome·Codex Gmail 연결·
Keychain 등록까지 전부 처음 구성한 검증은 아닙니다. 다른 계정의 최초
설치 성공이나 장기 운영 안정성으로 확대하지 않습니다.


## v0.2.2 availability regression

2026-10-13 저녁 실제 예약 실행에서 Gmail 검색 도구가 일시 오류를 반환하는
상황을 재현했습니다. 동일 환경의 후속 읽기 전용 검색은 성공했습니다.
수정 전 새 회귀 시나리오 3개가 실패했고, 수정 후 전체 31개와 추가된
지속 오류 상한·요청 만료 전달 검사 2개가 통과했습니다. 총 33개입니다.

수정은 같은 메일 읽기 요청의 제한된 재시도와 비식별 오류 코드 기록에
한정합니다. 인증/OTP 요청 횟수를 늘리지 않고, 기존 보안 검사를 유지합니다.
개인용 앱 적용 후 서명 검증을 통과했고 macOS 접근성 재승인이 필요했습니다.
실제 복구 결과는 승인 후 별도로 확인합니다.


## v0.2.2 로고와 배포 앱

투명 PNG 로고를 16–1024px ICNS 표현으로 변환하고 앱의 CFBundleIconFile에
연결했습니다. 개인용 앱은 기존 식별자를 유지해 교체했고 서명을 검증했습니다.
공유 앱에는 Community 전용 경로와 키체인 이름만 포함합니다. 개인 설정,
키체인 값, 메일, 브라우저 프로필은 포함하지 않습니다.

재시도 수정과 아이콘 적용 후 실제 VPN 복구는 사용자의 macOS 접근성
재승인까지 보류합니다. 오전 v0.2.1의 로그인 성공을 v0.2.2 재검증으로
표현하지 않습니다.

최종 Apple Silicon 배포 앱의 Mach-O 최소 버전은 13.0이며, 엄격한 코드 서명
검증과 초기 `--status` 결과 `{}`를 확인했습니다. macOS 시스템 아이콘 API가
개인용 설치 경로에서 새 로고를 반환하는 것을 이미지로 확인했습니다.


## v0.2.3 화면 전환 복구

2026-10-13 22:47 KST, 수정한 실행 코드를 기존 앱의 예약 환경에서 검증해
`connected`, `attempts: 1`, `reusedConnection: false`, `native: SA`, `ssh: ok`,
`modelCallsThisRun: 0`을 확인했습니다. 실제 계정 없는 격리 Chrome 검사에서
기존 Frame 참조는 iframe 교체 후 실패하고, 수정한 준비 대기는 새 Frame을
찾았습니다. 신뢰되지 않은 iframe origin은 계속 거부합니다. 정확한 포털
origin·경로·단일 클라이언트 헤더가 모두 있어야 중복 이동을 생략합니다.

현재 연결을 유지한 채 최종 앱에 반영합니다. 최종 재서명 후 예약 실행의
접근성은 사용자 재승인 후 별도로 확인해야 합니다. 다른 사용자·새 OS
설치 또는 장기 운영 검증으로 확대하지 않습니다.

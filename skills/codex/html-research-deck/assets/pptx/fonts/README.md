Pretendard Regular and Bold (OpenType), from https://github.com/orioncactus/pretendard, SIL Open Font License 1.1 (`LICENSE-Pretendard.txt`): free to install, copy and embed.
The default family for every PPTX deck of this skill (Hangul, Latin, Greek, digits in one face; user choice 2026-10-01 for Mac + Windows use). `scripts/pptx/ensure_font.py` installs these files into the user's font folder automatically when Pretendard is missing (macOS ~/Library/Fonts, Linux ~/.local/share/fonts, Windows per-user fonts); `createDeck()` and `finalize.mjs` call it. On a machine that only opens the deck, install the .otf files by hand (Windows: right-click → Install for all users).

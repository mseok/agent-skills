# References linked to the content they support

A bibliography at the bottom of a slide does not tell the audience which item it supports. Associate each external claim, compound, potency value, model fact and reused figure with its actual source at the point of use.

Use either a short author–year label beside the relevant content or a small readable marker such as `[1]` beside that content with the same marker in the slide footer. Marker scope must be unambiguous: keep it adjacent to the compound name, claim sentence, value or panel caption, not merely in the slide title. Multiple panels can share a marker when they share the source. Use deck-wide numeric references starting at [1], assigned consecutively by first use in the final presentation reading order. Reuse the same number for the same source on later slides. The first cited slide must begin with [1]; never retain historical IDs such as [20] for a newly inserted opening figure. Keep a source key (DOI/PDB/record ID) separate from its displayed number. After inserting/reordering slides or sources, regenerate the numbering in body markers, sorted slide footers, notes and citation map together. Sort each slide footer numerically ascending, even when the authoring code added the sources in a different order. Never leave unmatched markers or unanchored footer entries.

For a compound, separate what each citation establishes. A paper reporting an inhibitor supports its reported identity/activity; the chemical image’s source or drawing record establishes how that displayed structure was obtained; a PDB supports an experimentally deposited pose. A screening rank is the present study’s own result and does not need an external reference. If these origins differ, record each separately rather than imply that one citation establishes all of them. For example, `SB216763 [3]` can link to its original inhibitor paper, while notes retain the identifier/SMILES and source used to draw its structure. A reference to a library alone does not establish the molecule’s discovery or inhibitory activity.

Keep source author names and `et al.` in Latin on Korean slides. Footer text uses compact author–journal–year or APA style and the current readable font-size policy. If adjacent citations make a row too crowded, reflow the row/footer; do not shrink the citations or drop their links. Do not add external references or a “This study” citation to this study’s own analysis.

Retain an auditable local citation map with slide ID, supported object/claim, visible marker, source DOI/URL, exact supporting section/figure/table, and what the source establishes. Notes carry the full citation and source conditions. Check that the source actually supports the displayed claim, rather than adding a plausible title.

Before delivery, inspect the rendered slide and verify both directions: every marker resolves to a reference, and every displayed reference has identifiable supported content. For compounds, independently check the name/chemical identifier and the paper’s role. This is a semantic check, not just counting reference text boxes.

Name footer text objects with the `reference-footer:` prefix (the style-kit `reference()` helper does this). Run `scripts/check_slide_conventions.py` on the exported PPTX. It verifies introduction of contiguous reference numbers from 1, ascending footer order and body/footer correspondence. It does not establish whether a source supports a claim; inspect the citation map and reading order separately.

## Provenance details that judges found missing

- Take author, journal, year, volume and DOI from the retained bibliographic record (the references JSON or DOI metadata), never from memory or by retyping; reconcile each displayed year with the record before delivery (a footer once said 2018 where the record said 2019).
- Data provenance is a source too: an external dataset used on the slide (ChEMBL/BindingDB activity records, an annotation or knowledge-graph set, a database release) gets a marker where its numbers appear, and the notes carry a locator that resolves to the actual record/release/file, not a site home page.
- Attach each marker to the step, value or claim it supports, not to a row heading or a generic label; a reference that supports a structure does not sit on a downstream biological claim.
- State the species/system next to the claim when it is not human (mouse expression or knockout) or not the stated cell type, in the slide wording or its marker text.
- Speaker notes are readable prose in the deck's language: one block per marker with full citation, what it supports, figure/panel, species/assay conditions and locator. No raw JSON dumps, no build-path artifacts such as `../`.
- Mechanistic statements inside a diagram (transfer without an intermediate, downstream activation) and every named reference compound or caption that names a second structure need their own marker. Define abbreviations on first use (an undefined “KG” on a slide is a defect) and keep one name per entity across slides (BIO vs 6BIO).
- Asset and source locations in notes are host-qualified (`local:/abs/path`, `messi:/abs/path`), not bare absolute paths.
- A number the brief supplies but the retained records cannot reproduce (an annotation without recovered assay conditions) is shown with a short visible qualifier next to it (e.g. “조건 미확인” / “conditions not recovered”) and a lighter weight than values with a record, not at equal weight in a row; the notes name the missing record. Never print a range or aggregate in notes that the retained rows contradict.
- `check_slide_conventions.py` accepts new markers introduced in row-major or column-major reading order within a slide; renumber so the order is ascending in the order a person reads (usually left→right, top→bottom), even when two columns cross.
- Methods compared in a native chart carry their own marker in the category label text (`DiffDock-L [3]`, `DynamicBind [4]`): `check_slide_conventions.py` reads chart categories, series names and titles, and every footer entry then has a visible item. Do not bundle several references on a closing line (“peers [3][4][5]”) or add a separate gray “Peers: …” line.

**A marker must be backed by its source's own statement.** Before attaching a marker to a claim, check that the cited abstract/record actually says it (r22: CHIR99021 called a GSK3 inhibitor but cited to a paper whose abstract calls it a Wnt activator; use the primary paper or one already in the deck). Counts taken from a derived dataset (knowledge-graph export, ChEMBL release) carry that dataset's own marker on the slide where they first appear, not on a later slide.
